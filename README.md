# Student Registration Form

A responsive and interactive student registration form built using HTML, CSS, and JavaScript. The project focuses on form validation, DOM manipulation, user interaction, and session storage.

## About the Project

This project allows users to enter their personal and course information through a registration form. JavaScript is used to validate the form, display error messages, manage registered students, and dynamically update the saved users section.

## Features

- Student registration form
- Name, email, age, password, and course fields
- Form validation
- Email validation
- Age validation
- Password length validation
- Confirm password matching
- Show/hide password functionality
- Light/Dark mode toggle
- Dynamic student cards
- Add and remove registered students
- Student count
- Session Storage for saving user data
- No page refresh required
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Arrays
- Functions
- Event Listeners
- Session Storage

## How It Works

1. The user fills in the registration form.
2. JavaScript validates the entered information.
3. Error messages are displayed for invalid fields.
4. After successful validation, the student is added to the registered users list.
5. Student information is displayed dynamically using DOM manipulation.
6. User data is stored in Session Storage.
7. The theme can be switched between light and dark mode.

## Purpose

This project was created as a front-end practice project to strengthen JavaScript fundamentals, especially DOM manipulation, form validation, event handling, arrays, functions, and browser storage.
